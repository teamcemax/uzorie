# 4.0 — УЗОРЬЕ

- Новое название, авторский знак переплетения и favicon в нескольких форматах.
- Народ и культурный контекст стали первым уровнем навигации.
- Возвращён самостоятельный пошаговый экран с оглавлением, самопроверкой, заметками и увеличением схемы.
- Анимации полностью удалены. Для каждого курса — отдельный итоговый рисунок и семь статичных изображений этапов.
- 36 учебных изделий вместо прежних 87 преимущественно шаблонных карточек. Список народов содержит 11 наполненных разделов, без пустых счётчиков.
- В каждом курсе приведён источник культурного контекста и обозначены границы авторской адаптации.
- Страница самодостаточна: нет загрузки каталога через fetch.
- Сохранён экспорт и импорт личных данных; прежние записи доступны как архив, но не считаются прохождением новых заданий.
