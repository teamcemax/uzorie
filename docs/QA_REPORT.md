## Исправлено в ходе проверки
При смене страницы из активного поля поиска браузер мог послать событие change со старого поля. Добавлена защита от обработки устаревших событий во время перерисовки.
Исправлен размер логотипа, чтобы SVG не перекрывал название.
Уточнены схемы красного заполнения, треугольного бордюра и цветовой последовательности ткачества.

## Границы проверки
Использован Chromium / Playwright. Среда запрещает нативный переход на file:// и HTTP/HTTPS-страницы (`ERR_BLOCKED_BY_ADMINISTRATOR`), поэтому HTML загружался через set_content. Для проверки состояния применялся изолированный адаптер localStorage ТОЛЬКО в тесте; его нет в выпускаемом HTML. Отдельно проверено, что при недоступном хранилище каталог всё равно открывается и показывается предупреждение.
Нативное сохранение данных в браузере пользователя, его GitHub-публикация, Firefox/Safari, физический принтер и реальное учебное занятие не проверены. На своём устройстве нужно завершить один шаг и проверить его после обновления страницы.
Все тестовые работы и наблюдения существовали только в изолированном браузере QA; в выпускаемом сайте нет вымышленных результатов апробации.

Эти проверки относятся к коду и интерфейсу. Они не заменяют культурную экспертизу рисунков и проверку методик мастером.
