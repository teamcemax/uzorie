# УЗОРЬЕ
## Ремёсла народов России

**Народ → культурный контекст → конкретная вещь → техника в процессе.**

В этой редакции нет анимаций и общих GIF, переименованных под разные курсы. У каждого изделия свой рисунок и семь пошаговых иллюстрированных этапов. В каталоге сначала выбирается народ, затем уровень и приём внутри курса.

## Запуск

Открой `index.html` в браузере либо загрузи файлы этого архива в корень существующего GitHub Pages-репозитория. Каталог, стили, код и SVG-изображения встроены в HTML; дополнительных сборок, JSON-запросов и регистрации не требуется. Файлы favicon предоставлены для браузеров и устройств, предпочитающих отдельный значок.

Если сайт уже размещён в GitHub Pages, замени `index.html` и добавь файлы значков из архива. Настройки публикации оставь прежними. Инструкция — `START_HERE.txt`.

## Функции

- Страницы 11 народов и культурных традиций; только заполненные разделы.
- 36 различных изделий; 252 этапа; 288 статичных SVG-иллюстраций.
- Совместные фильтры по народу, уровню, технике и поисковому запросу.
- Отдельный экран каждого шага, список этапов, самопроверка, заметки и таймер.
- Увеличение схем, 36 контурных шаблонов, печатные маршруты.
- Материалы на одного человека и расчёт на группу. Неизмеренный расход не подменяется придуманными нормами.
- Личная мастерская с фотографиями, экспорт/импорт JSON; отдельный архив прежних записей.
- Журнал реальных пробных занятий и CSV-экспорт.
- Авторский знак переплетения, SVG/PNG/ICO favicon, отдельный заголовок каждой страницы.

## Культурный контекст и границы

Источники музеев и профильных организаций указаны непосредственно в курсах. Они подтверждают описанный культурный контекст, но не являются рецензиями на наши рисунки, размеры или инструкции. Все композиции разработаны для обучения; их нельзя выдавать за музейные реконструкции или исключительную собственность одного народа. Ромб, цветок или шов могут встречаться в разных культурах.

Полноценного охвата всех народов и ремёсел в этой версии нет. Каталог осознанно пересобран: вместо 87 в основном повторяющихся общих карточек опубликованы 36 отдельных изделий с источниками и своими рисунками. Старые личные данные не считаются прохождением новых курсов.

Перед групповым занятием нужна проверка методики преподавателем или мастером. Время в курсах — предварительная авторская оценка. Печатный размер счётной вышивки необходимо соотнести с реальной плотностью канвы. Бумажная роспись не является изготовлением фарфора; бумажная мозаика не обучает традиционному шву на коже.
